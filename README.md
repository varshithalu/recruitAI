
# 📄 RecruitAI – AI Resume Screening Platform

## 📌 Overview

RecruitAI is an AI-powered recruitment platform designed to automate resume screening and candidate shortlisting. The system compares uploaded resumes with Job Descriptions using Natural Language Processing and semantic matching.

The platform helps recruiters reduce manual screening time and improves hiring efficiency through intelligent candidate ranking.

---

## 🚀 Features

* Resume upload system
* Job Description upload
* AI-based resume analysis
* Semantic similarity matching
* Candidate ranking system
* ATS-style screening workflow
* Interactive frontend interface
* Real-time scoring system

---

## 🧠 Workflow

1. Recruiter uploads Job Description
2. Candidate uploads resume
3. Text extraction and preprocessing performed
4. NLP embeddings generated
5. Similarity score calculated
6. Candidate ranking generated
7. Results displayed on dashboard
